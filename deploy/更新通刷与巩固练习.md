# 已有腾讯云部署升级说明

适用于现有 `/home/ubuntu/cjpractice15` 压缩包部署，使用 `compose.existing-caddy.yaml`。不运行 prepare_cloud、不覆盖 .env、不重新导题、不修改 Caddy，不操作 tk 项目的容器与数据库。

下载本次确认的 GitHub 提交源码包到 `~/cjpractice15-update.tar.gz` 后，在 FinalShell 执行以下命令。保持同一个终端会话，任一步报错先停止并保留输出，不跳过迁移。

```sh
cd ~/cjpractice15
umask 077
backup_dir="$HOME/cjpractice15-backups/learning-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$backup_dir"
sudo docker compose -f compose.existing-caddy.yaml exec -T practice-db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > "$backup_dir/database.dump" &&
test -s "$backup_dir/database.dump" &&
tar -czf "$backup_dir/source.tar.gz" config practice templates static tools docs deploy Dockerfile requirements.txt compose.existing-caddy.yaml &&
tar -xzf ~/cjpractice15-update.tar.gz -C ~/cjpractice15 --strip-components=1 &&
sudo docker compose -f compose.existing-caddy.yaml build --build-arg PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple &&
sudo docker compose -f compose.existing-caddy.yaml stop practice-app &&
sudo docker compose -f compose.existing-caddy.yaml run --rm practice-app python manage.py migrate --noinput &&
sudo docker compose -f compose.existing-caddy.yaml run --rm practice-app python manage.py collectstatic --noinput &&
sudo docker compose -f compose.existing-caddy.yaml run --rm practice-app python manage.py check --deploy &&
sudo docker compose -f compose.existing-caddy.yaml up -d --no-deps practice-app &&
curl --retry 10 --retry-all-errors --retry-delay 2 --retry-max-time 45 --max-time 10 --fail --silent --show-error -o /dev/null -w '登录页 HTTP %{http_code}\n' -H 'Host: dt.riskai93.cn' -H 'X-Forwarded-Proto: https' http://127.0.0.1:18080/login/
```

源码包指 GitHub 对应提交的 codeload 压缩包，顶层有一层目录；不要对平铺发布包使用 `--strip-components=1`。已确认仓库不含 `.env`，解压不替换服务器现有 `.env`。数据库备份含个人记录，应只留在服务器受限目录，不上传聊天或 GitHub。

备份在停服之前进行，是升级前的数据库快照；不能承诺包含之后新提交的答案。应用只在构建完成后暂停，迁移与静态收集成功后恢复。若迁移失败，应用会保持停止，保留报错及备份，确认后再处理，不清空数据库、不执行 down -v。

更新后访问域名登录，浏览器强制刷新。验证顺序练习中的“全部未练题”、累计通刷进度、巩固练习和原有错题本。不要勾选“重新通刷”来测试保留进度。
