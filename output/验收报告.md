# 长江学堂在线练习应用 · 本地验收

日期：2026-10-26。交付形态：可部署源码及容器配置；未操作云服务器。

## 功能

管理员创建账号（单个 / CSV 批量）、首次强制改密、账号启停与重置密码；不提供注册。四板块多选，车险承保 / 理赔细分，顺序 / 随机 / 限时模拟练习，简答题参考答案与自评，按账号保存记录，错题重练与手动移除，移除后再次答错重新加入。

普通练习逐题显示答案；模拟交卷前不返回标准答案与解析。服务器管理截止时间和评分，浏览器刷新可恢复已提交答案。修改系统时钟的浏览器测试未提前结束模拟。修改题库不会更改历史快照。

## 题库

五份 PDF 共 304 页，识别 1,511 题，启用 1,506 题：车险 806、非车险 300、健康险 200、农险 200。5 题因原文件缺漏或编号异常隔离，详情见 `data/import-report.md`。原始 PDF 未改动；未补造答案或解析。

已启用题目的选项与答案结构校验无错误，解析器针对已知答案格式的泄漏扫描未发现残留。该扫描不等同逐字人工复核，也不构成保险业务答案的正确性审定。原题库存在“多选题仅列单个答案”等类型差异，报告已标注，程序保留原文标准答案。
