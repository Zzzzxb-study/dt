# 通刷与巩固练习

## 使用方式

- 顺序练习可选择“全部未练题”、20/50/100/300 题，或自定义 1—10000 题。全部未练题会一次创建所选范围本轮尚未提交的题目，不受 300 题上限限制。
- 当前范围由板块、车险承保/理赔范围和题型共同确定；支持同时选择多个板块。
- 首页显示本轮已练、范围总数、剩余题数和已掌握题数。顺序作答无论对错都推进通刷，其他模式不推进通刷。
- 继续上次练习进入最近创建的未完成练习；打开练习时默认定位第一道未提交题。旧练习也可从练习记录继续。
- 本轮练完后不自动重复，提示选择重新通刷或巩固。重新通刷仅重置所选范围的本轮进度，保留作答、错题和掌握状态。旧轮次的练习仍可作答、计入掌握和错题，但不推进新轮次覆盖率。

## 巩固规则

未练题首先进入题组；没有足够未练题时，从已练题按权重随机选取剩余名额，不重复凑题。

| 已练题状态 | 抽取权重 |
| --- | --- |
| 未掌握且在个人错题本中 | 6 |
| 其他未掌握题 | 3 |
| 已掌握题 | 0.3 |

权重是每次抽取的相对倾向，不是固定配额或出题次数保证。选取题量覆盖整个范围时，所有题都会入组。未练题足够填满题组时，已练题暂不进入。

客观题在不同练习中连续答对 3 次即视为掌握；简答题按照“已掌握/未掌握”自评立即更新。再次答错会清除连续答对状态，并按原有规则重新加入错题本。重复提交同一道练习题不增加掌握次数。

模拟交卷前不更新掌握状态，交卷后记录最终结果，未答题按错误处理。模拟仍只选客观题、每次 1—300 题，抽题不受掌握状态影响。随机练习也保留原来均匀打乱的方式。

已掌握不会自动移出错题本。错题仍支持手动移除；再次答错恢复。

## 兼容旧数据

数据库迁移 0002 新增个人题目进度，0003 从历史作答重建顺序覆盖和连续答对状态。未交卷模拟不计入。原题库、账号、历史答题和错题不会删除。升级前应备份数据库；历史记录越多，重建所需时间越长。

当前页面只加载当前题目的完整题干与答案快照；答题卡读取轻量状态，避免每翻一题读取数百份完整快照。
