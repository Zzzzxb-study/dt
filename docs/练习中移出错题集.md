# 练习中移出错题集

非模拟练习中，当前题目在个人错题集内时，答题区下方显示“移出错题集”按钮。支持在答题前和查看答案后移除，操作前会确认。取消不会修改记录。

确认后留在当前题，显示“已移出错题集”，可继续作答或下一题。移除不会替你提交答案、删除当前练习中的题目、改变成绩或标记掌握。历史作答保留，以后新建的错题练习不再选取此题；再次答错会重新加入。

原来的错题列表移除入口继续可用。服务端校验账号、练习题与错题是否对应，仅允许 POST 并沿用 CSRF 保护；不接受任意返回地址。模拟过程中不展示错题状态，也不能通过模拟题上下文执行移除。

本次仅调整视图和模板，无数据库结构或依赖变化。更新服务器上的三个应用文件后重新构建、启动 practice-app 即可，不需要迁移或重新导入题库：

- practice/views.py
- templates/practice/session.html
- templates/practice/practice_mistake.html
